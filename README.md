# Drip Store — Front-end

Aplicação React desenvolvida para o projeto final de Front-end do curso Geração Tech 4.0, baseada no layout Digital Store.

## Integrantes da equipe

- Vinicius
- Kayuusha

## Como executar

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Gere a versão de produção:
```bash
npm run build
```
